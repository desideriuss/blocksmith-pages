🔒 Privacy Policy

Blocksmith — Last Updated: August 28, 2026

Thank you for using the Blocksmith application ("the App"). Your privacy is important to us. This policy explains what information the App collects, how it is used, and how it is protected.

Important: Our App does not collect or store personally identifiable information (name, email, phone number, etc.). All accounts are created anonymously.

1. Data Collected

1.1 Session ID (Anonymous Account)

The App automatically creates an anonymous account on first launch. This account contains a device-specific random identifier (UUID) and cannot be linked to you personally. The account is reset when you delete and reinstall the App.

1.2 Game Data

The following game statistics are stored on the server:

  • Game score and high score
  • Total games played
  • Lines cleared
  • Maximum combo
  • Levels completed
  • Experience points (XP) and level
  • Badges earned

This data is displayed only on the leaderboard and profile screens and is not shared with third parties.

1.3 Profile Information (Optional)

Users may optionally set the following:

  • Display name (nickname)
  • Avatar style (auto-generated via DiceBear API, no real photos)

This information is optional; the App can be used without providing any profile data.

1.4 Friend List

Users may optionally add other users as friends. The friend system works exclusively with anonymous identifiers and contains no real-person information.

1.5 Local Data (On-Device Only)

The following data is stored only on your device and is never sent to any server:

  • Sound settings (mute state)
  • Theme preference
  • Current game state (in-progress game)

1.6 Analytics Data

In-app event logs (e.g., game results, combo counts) are recorded in the Supabase database. This data is used for app development and debugging purposes.

2. Third-Party Services

The App uses the following third-party services:

  • Supabase — Authentication, database, and real-time notifications. (Privacy Policy)
  • DiceBear — Profile avatar generation (no real photos). (Privacy Policy)

3. Purpose of Data Use

  • Operating the leaderboard and social features
  • Recording game statistics
  • Improving app performance
  • Detecting and fixing bugs

4. Data Sharing

Collected data:

  • Is not sold to third parties
  • Is not shared with advertising companies
  • Is displayed publicly on the leaderboard only for scores voluntarily created by the user

5. Data Security

Your data is transmitted encrypted over HTTPS and hosted on secure servers by Supabase.

6. Children's Privacy

The App does not knowingly collect personal information from children under the age of 13. Users under 13 are advised to use the App under parental supervision.

7. Data Deletion

When you delete the App from your device, all local data is permanently removed. If you would like us to delete your server-side data, please contact us at the address below.

8. Changes to This Policy

This privacy policy may be updated from time to time. Changes will be published on this page.
